## 1. ERP 웹 재고 현황 조회 쿼리 리팩토링 및 환경관리 모듈 개발
**더존비즈온 (2022.02 ~ 2024.03)**

> 💡 **[과제 요약 - 자기조절력]** 웹 ERP 재고 조회 시 미사용 컬럼과 잘못된 JOIN으로 응답이 5분 이상 걸리는 상황에서, 필수 데이터만 조회하도록 WITH절 기반으로 재설계해 5초 이내로 단축했습니다.

### 📌 프로젝트 개요 및 문제 상황
- **역할:** SCM 개발 Unit 백엔드 개발 및 쿼리 튜닝
- **사용 기술:** Spring Boot, JavaScript, Oracle, Git
- **상황:** 레거시 다중 조인(JOIN) 구조와 미사용 컬럼 데이터 호출로 인해 ERP 재고 현황 조회가 최대 3~5분까지 지연되는 심각한 성능 병목 발생. 데이터 누적으로 인한 장기적인 부하 위험 존재.

### 🛠 해결 과정 (Action)
- **구조 분석 및 재설계:** 실행 계획(Explain Plan)을 분석하여 불필요한 결합(Cartesian Product 등)을 식별하고 걷어냄.
- **모듈화 구조 도입:** 복잡한 서브쿼리 구조를 **WITH절**을 활용하여 임시 테이블 형태로 모듈화하고, 데이터 접근 경로를 최적화함.
- **부하 방어 로직:** 필수 조회 조건을 시스템적으로 강제하고, 장기적인 부하 분산을 위해 웹 소켓(WebSocket) 도입을 검토 및 설계에 반영.
- **모듈 신규 개발:** SCM 환경관리 모듈의 신규 페이지를 구축하고, 반복 사용되는 로직을 공통 함수(Utility)로 분리하여 유지보수성을 높임.

### 📈 성과 (Result)
- 데이터 조회 응답 시간을 **5분(300초)에서 10초 이내로 대폭 단축**.
- 서버 리소스 부하 경감 및 안정적인 시스템 운영 환경 확보.

## 2. API 기반 물류 주문 수집 배치 및 이기종 시스템 연동
**티시스 (2024.10 ~ 2025.10)**

> 💡 **[과제 요약 - 자기동기력]** 엑셀 업로드 양식 불일치로 오류가 잦은 상황에서, 수작업을 없애고자 외부 물류 API를 호출해 유효성을 검증하고 ERP로 전송하는 Python 배치를 개발해 업무를 2시간 절감했습니다.

### 📌 프로젝트 개요 및 문제 상황
- **역할:** ERP 10 전용화면 개발 및 Python 기반 업무 자동화 파이프라인 구축
- **사용 기술:** Spring Boot, Python, RESTful API, Oracle
- **상황:** 외부 물류 데이터 취합을 전적으로 수기 엑셀 업로드에 의존하고 있어, 양식 불일치 및 휴먼 에러로 인한 오류 문의가 매일 발생. 유지보수 및 CS 응대에 과도한 개발 공수 낭비.

### 🛠 해결 과정 (Action)
- **API 스크래핑 및 배치 파이프라인 구축:** 외부 물류 시스템의 API를 호출하여 주문 데이터를 스크래핑(Scraping)하고 자동으로 수집하는 Python 데몬 배치 프로세스 설계.
- **유효성 검증 자동화:** 수집된 데이터가 ERP 스키마에 맞는지 검증(Validation) 및 정제하는 전처리 로직 구현.
- **데이터 적재 파이프라인:** 검증된 데이터를 ERP 데이터베이스에 안정적으로 일괄 전송(Bulk Insert)하는 파이프라인 구축.

### 📈 성과 (Result)
- 엑셀 수기 업로드 과정을 완전히 자동화하여 실무자의 **일평균 데이터 입력 업무 2시간 절감**.
- 데이터 입력 오타로 인한 정합성 오류 원천 차단.

## 3. 전자결재(아마란스/비즈박스) 연동 표준화 및 매뉴얼 자산화
**더존비즈온 (2022.02 ~ 2024.03)**

> 💡 **[과제 요약 - 협업 및 소통 역량]** 전자결재 연동이 개인 경험에 의존해 병목이 잦은 상황에서, 특정 인원 의존성을 없애고자 API 호출 순서와 에러 가이드를 위키에 표준화해 누구나 연동할 수 있게 했습니다.

### 📌 프로젝트 개요 및 문제 상황
- **역할:** 아마란스 및 비즈박스 전자결재 API 연동 및 사내 개발 문화 개선
- **상황:** 서로 다른 플랫폼 간 전자결재 연동 업무가 명확한 문서 없이 개인의 경험에만 의존됨. 담당자 부재 시 작업 병목 현상 및 타 부서와의 API 스펙 소통 착오 빈번.

### 🛠 해결 과정 (Action)
- **표준 가이드라인 작성:** 시스템별 API 호출 순서(Sequence), 에러 코드(HTTP Status 및 커스텀 코드)별 대응 가이드, 단계별 테스트 시나리오를 작성.
- **위키 배포 및 지식 자산화:** 사내 위키(Wiki)에 해당 문서를 배포하여 누구나 쉽게 참고하고 검증할 수 있는 환경 조성.
- **협업 프로세스 개선:** 외부 API 연동 시 후처리(Post-processing) 로직에 대한 팀 내 코드 리뷰 및 표준화 템플릿 적용.

### 📈 성과 (Result)
- 특정 개발자에게 집중되던 업무 병목 해소 및 부서 간 커뮤니케이션 비용 절감.
- 누구나 쉽게 전자결재를 연동하고 검증할 수 있는 환경 구축.
