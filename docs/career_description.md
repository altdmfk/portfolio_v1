# 경력기술서

과제마다 한 줄 요약과 상황·행동·결과를 적었습니다. 경력 과제는 과제 통과에 필요한 만큼만 간략히 담았습니다.

| # | 과제 | 능력 | 상황 | 행동 | 결과 |
|---|------|------|------|------|------|
| 1 | 달리기 중단 후 조건 점검·재도전 (2026.07.13~15) | 자기조절력 | 달리기 중 호흡 곤란과 갈비뼈 통증으로 멈췄고, 루틴이 끊길까 불안했다. | 복장·수면·저녁 식사 조건을 짚어 바꿨다. | 7월 15일 완주했다. |
| 2 | 다이어리 앱 계정 삭제 오류 | 자기동기력 | 삭제한 계정이 다른 브라우저에서 로그인됐고, 자동 테스트는 통과했다. | 직접 디버깅해 로컬 스토리지에 삭제 표시만 남기는 문제를 찾고, 클라우드 삭제 → 마커 기록 → 세션 종료 순서를 명시했다. | 계정이 정상 삭제됐다. |
| 3 | 전자결재 연동 표준화 (더존비즈온·티시스) | 대인관계력 | 연동 업무가 개인 경험에 의존해 병목과 소통 착오가 잦았다. | API 호출 순서, 에러 코드별 대응 가이드, 단계별 테스트 시나리오를 위키에 정리했다. | 누구나 연동하고 검증할 수 있게 됐다. |
| 4 | ERP 재고 조회 쿼리 리팩토링 (더존비즈온, 2022.02~2024.03) | 자기동기력 | 재고 현황 조회가 3분 이상 걸렸다. | 미사용 컬럼과 불필요한 결합을 정리하고 서브쿼리를 WITH절 기반 모듈 구조로 재설계했다. | 조회 시간 3분 → 10초. |
| 5 | 주문 수집 Python 배치 (티시스, 2024.10~2025.10) | 자기조절력 | 엑셀 업로드의 양식 불일치와 오타로 오류 문의가 잦았다. | 외부 물류 시스템 API로 주문을 수집하고 검증·정제해 ERP로 전송하는 배치를 만들었다. | 수기 입력 업무 일평균 2시간 절감. |
